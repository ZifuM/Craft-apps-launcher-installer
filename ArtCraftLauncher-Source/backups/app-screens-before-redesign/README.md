# App screens before the 2.3.0 redesign

The original App Manager, Your apps and app card implementations are preserved as classic methods in the current application. Enable Settings → Appearance → Classic app screens for immediate rollback without changing other features.

The main.rs and Cargo.toml files here are reference snapshots from 2.2.1. Do not overwrite the current source wholesale unless intentionally rolling back all later changes in those files.

The same Classic app screens setting also restores the previous per-app workspace layout after the 2.4.0 redesign.
